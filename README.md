# Monitor Bot for Ubuntu 24.04

ربات تلگرام برای پایش اتصال، اسکن IP، مدیریت مخزن و تعویض DNS پس از تأیید. روی اوبونتو با PHP CLI اجرا می‌شود. سرویس systemd پیام‌ها و دکمه‌های تلگرام را به‌صورت Long Polling می‌گیرد و کرون هر دقیقه پایش و اسکن را اجرا می‌کند. نیازی به دامنه، وب‌سرور یا پورت ورودی ندارد.

## نصب

روی Ubuntu 24.04 با دسترسی sudo و SSH فعال به مخزن خصوصی اجرا کنید:

```bash
git clone git@github.com:aligholamigw/monitor-bot-ubuntu.git && cd monitor-bot-ubuntu && sudo bash install.sh
```

اگر بستهٔ ZIP را منتقل کرده‌اید، پس از استخراج در پوشهٔ بسته `sudo bash install.sh` را اجرا کنید. در نصب اول، نشانی کامل Status، توکن ربات، شناسهٔ عددی مدیر تلگرام، Zone ID و توکن DNS کلودفلر و لینک کامل VLESS از ترمینال دریافت می‌شوند. برای مسیر مستقیم، ورودی اختیاری SOCKS5 را خالی بگذارید. مقادیر حساس در دستور نصب یا خروجی ترمینال ظاهر نمی‌شوند.

نصب‌کننده دسترسی به Status، Live، رکوردهای Cloudflare و Telegram را از همین سرور بررسی می‌کند. در صورت خطای دسترسی راه‌اندازی متوقف می‌شود. اگر مقصد مانیتورینگ از خود اوبونتو هم در دسترس نیست، از SOCKS5 مورداعتماد یا آدرس HTTPS مانیتورینگ استفاده کنید. برای اصلاح تنظیمات پس از خطای این مرحله، فایل `/etc/monitor-bot/config.php` را با `sudoedit` باز کنید و نصب را دوباره اجرا کنید.

## انتقال از سی‌پنل

ابتدا در ربات تعویض DNS را متوقف کنید و کرون نسخهٔ سی‌پنل را غیرفعال کنید. در صورت نیاز، فایل `state.json` را بعد از توقف کرون کپی کنید تا مخزن و صف اسکن منتقل شوند. سپس از پوشهٔ مخزن اجرا کنید:

```bash
sudo bash install.sh --switch-webhook --state /path/to/state.json
```

اگر مخزن و صف قبلی را نمی‌خواهید منتقل کنید، گزینهٔ `--state` و مسیر فایل را حذف کنید. `--switch-webhook` وب‌هوک قبلی را پس از بررسی اتصال حذف می‌کند و پیام‌های در صف تلگرام را حفظ می‌کند. تلگرام برای یک توکن فقط یکی از روش‌های Webhook و Long Polling را می‌پذیرد. نخستین نصب و انتقال داده، تغییر DNS را در حالت شبیه‌سازی و توقف قرار می‌دهند. بعد از نصب `/start` بفرستید و اسکن یا تغییر DNS را از دکمه‌ها فعال کنید.

## فایل‌ها و بررسی اجرا

| کاربرد | مسیر یا فرمان |
|---|---|
| برنامه | `/opt/monitor-bot` |
| تنظیمات خصوصی | `/etc/monitor-bot/config.php` |
| وضعیت و صف | `/var/lib/monitor-bot/state.json` |
| کرون دقیقه‌ای | `/etc/cron.d/monitor-bot` |
| وضعیت سرویس تلگرام | `sudo systemctl status monitor-bot-poll` |
| گزارش تلگرام | `sudo journalctl -u monitor-bot-poll -n 50` |
| گزارش پایش و اسکن | `sudo journalctl -t monitor-bot-cron -n 50` |

نصب فقط فایل‌های مربوط به Monitor Bot، کاربر محدود `monitorbot` و پیش‌نیازهای PHP CLI، cURL و cron را ایجاد می‌کند. تنظیمات پاسارگارد، Docker، فایروال و پورت‌های سرور به آن مربوط نیستند. ارتباط تلگرام و Cloudflare خروجی HTTPS است. مانیتورینگ از نشانی و پورت تعریف‌شده در تنظیمات خوانده می‌شود.
